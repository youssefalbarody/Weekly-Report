# Weekly Order Performance Report

تطبيق HTML/JavaScript لإنشاء تقرير الأداء الأسبوعي العربي من Excel أو CSV أو Google Sheets منشورة. ملف [simple.html](D:\report\simple.html) هو المصدر البصري الوحيد للوحة التقرير؛ تُحقن عناصر التحكم خارج لوحة التقرير ولا تغير تصميم Stitch.

## التشغيل

```powershell
npm install
npm run dev
```

ثم افتح العنوان الذي يعرضه Vite وارفع ملفاً. لبناء نسخة إنتاجية استخدم `npm run build`، ولتشغيل اختبارات منطق المقاييس استخدم `npm test`.

## التعامل مع البيانات

- يقرأ ملف `تيست.xlsx` كما هو: أربع كتل متجاورة للتأكيدات والشحن والدعم وباقي البيانات، بدلاً من افتراض أن كل صف أوردر كامل.
- يحتفظ بكل سجل طبيعي بسجل `raw` الأصلي، وبـ `rawSheets` غير المعدّلة، ثم يمرره إلى طبقة التحليل.
- عند انخفاض ثقة القراءة، تظهر شاشة mapping تسمح بإعادة تعيين كل كتلة أو تجاهلها.
- القيم المحسوبة والصفر الحقيقي والقيم غير المدعومة (`::`) والـ manual overrides مستقلة. يتم حفظ التعديلات اليدوية محلياً في المتصفح ولا تعدّل ملف المصدر.
- ارفع الأسبوع الحالي والأسبوع السابق كملفين منفصلين. تُحلل البيانات منفصلة ثم تُحسب فروقات النسبة بالنقاط المئوية؛ لا تُدمج الملفات.
- اختر التاريخ من عناصر التحكم. إن احتوى المصدر على حقل تاريخ معروف تُفلتر السجلات؛ وإلا يحدّث الاختيار عنوان التقرير فقط ويظهر تنبيه واضح.
- عند تعدد التجار تظهر قائمة اختيار؛ عند وجود تاجر واحد يُختار تلقائياً.
- تُعرض كل الأرقام والنسب والتواريخ بالأرقام الإنجليزية، بما في ذلك إدخال القيم اليدوية والتصدير.

## Google Sheets

خيار Google Sheets يستخدم رابط CSV منشور أو رابطاً يمكن تحويله إلى `export?format=csv`، ثم يمر عبر طبقة التحميل والتطبيع والتحليل ذاتها. لا توجد مفاتيح أو بيانات اعتماد في الواجهة. للملفات الخاصة، أضف endpoint خادماً يقوم بـ OAuth ويعيد CSV/JSON إلى `parseGoogleSheet`؛ لا تحتاج أي طبقة تحليل جديدة.

## الملاحظات

تظهر المقارنات السابقة كـ `::` حتى تُرفع بيانات أسبوع سابق. يمكن إدخال الحقول غير المتاحة يدوياً مباشرةً في التقرير؛ لا يمكن تعديل الحقول المحسوبة. التصدير إلى PNG/PDF يلتقط `#report-canvas` فقط، فلا يشمل الرفع أو اختيار الفترة أو التحقق أو أزرار التصدير، كما يلغي إظهار حدود الحقول القابلة للتحرير أثناء الالتقاط.

## النشر

يتضمن المستودع مسار GitHub Pages عبر GitHub Actions. بعد رفع الفرع `main`، فعّل **Settings → Pages → Build and deployment → GitHub Actions** إن لم تكن مفعّلة؛ ثم ينشر المسار أحدث مجلد `dist` تلقائياً.
